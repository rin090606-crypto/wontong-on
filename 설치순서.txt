원통ON 시험범위 관리자 등록 설치 순서

1. ZIP 압축을 풉니다.

2. Supabase → SQL Editor → New query
   supabase/exam_scopes.sql 전체를 붙여넣고 Run.

3. ZIP의 app 폴더를
   C:\Users\young\wontong-on 안에 붙여넣습니다.
   같은 파일은 '대상 폴더의 파일 바꾸기'.

4. 관리자 대시보드 메뉴 추가:
   관리자메뉴추가.txt의 항목을
   app/manager/page.tsx의 menuItems 배열에 추가합니다.

5. 서버 실행:
   npm.cmd run dev

6. 관리자 시험범위:
   http://localhost:3000/manager/exams

7. 학생 시험범위:
   http://localhost:3000/exam

8. 같은 학년·과목을 다시 저장하면 기존 범위가 수정됩니다.
   삭제 버튼으로 해당 과목을 제거할 수 있습니다.
   학년에 등록된 과목이 하나도 없으면 '시험범위 준비 중'이 표시됩니다.

9. 배포:
   git add .
   git commit -m "feat: add exam scope management"
   git push origin main
